# Nava Bhasha — The Nine Tongues League

A 30-minute-a-day language mastery system, built as a game.

Nine language tracks mapped to the nine grahas — Tamil (Surya), Malayalam (Chandra), Telugu (Mangala), Hindi (Budha), German (Guru), Spanish (Shukra), English US (Shani), English UK (Rahu), English core (Ketu) — played against one opponent: the Forgetting Curve.

- `index.html` — the league hub page (scoreboard, weekly rotation, Week 1 placement schedule, mechanics, 90-day win conditions)
- `nava-bhasha-plan.md` — the full game design: session structure, game-theory mechanics, levels, points economy
- `state.md` — the live scoreboard (levels, points, streak); if it isn't written there, it didn't happen

League starts Wednesday, November 18, 2026. Daily session card at 8:15 PM CT.
